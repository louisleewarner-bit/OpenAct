# Documents: treatments and outlines

One profile for pitch documents, treatments and series outlines. It is prose, not a script: headings (bold capitals), paragraphs, and a centred title. No screenplay indents, no (MORE) or (CONT'D), no scene numbers.

There is no published standard for treatment length or layout (unverified); the review only reports the page count. BBC Writersroom open calls want a full script, not a treatment or outline; the review flags a treatment if that target is chosen.
