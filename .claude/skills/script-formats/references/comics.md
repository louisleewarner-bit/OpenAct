# Comics

One profile, the **full script** (page by page, panel by panel). The plot-first method, where the artist draws from an outline and the writer scripts afterwards, needs no special layout. Status: format-verification.md, Comics table; source S34.

## Numbering
- Comic pages are elements, not printed pages: `PAGE ONE (FOUR PANELS)`. The panel count is filled in automatically, and each comic page starts a new printed page.
- Panels are numbered within each comic page: `PANEL 1`, `PANEL 2`.
- Lettering is numbered within each comic page in reading order: `1. NELL`, `2. CAPTION:`, `3. SFX:`. Numbering restarts on each new comic page, so the letterer can match balloons to art.
- Panel descriptions come first, then the lettering in the order it will be read, speakers left to right.

## Limits (review checks, from Dark Horse's guide)
- About 25 words a balloon or caption, about 50 a panel (`balloon-words`, `panel-words`).
- Three or four panels a page for action; quieter pages can hold more. The review flags more than six (`panels`).
- A US single issue is usually 22 story pages (20 to 24).

## Labels
Panel description (action), Speaker (character), Balloon (dialogue), Caption, SFX, and a direction in a balloon (parenthetical).
