# Later

Ideas parked outside the MVP. The architecture should leave room for each. Move an idea into prd.md only with a reason and a matching cut.

## P1 (next after the MVP)
- Dual dialogue side by side (import and export already keep it).
- Focus mode.
- DOCX file import, reusing the paste detector.
- Doubling flags in the scene-by-character chart.
- Routine and audience-participation tags, listed per scene.
- Export the chart and line counts as CSV or PDF.
- Compare two snapshots.
- Scene numbers on screen and in print.
- AV two-column scripts (documentary, corporate, ads), the one Final Draft template family OpenAct's single-column engine can't draw yet.
- More submission targets in the review (D-025), added as data when writers ask for them.
- Highlight a character's lines, in several highlighter colours (built in the prototype for one character).
- Proportional fonts for stage formats (Tinos and Arimo, metric-compatible with Times New Roman and Arial), measured from the font files so screen and PDF still match.
- Tidier Cast panel actions; an edge fade on the phone element bar (design critique).

## P2 (design for, build later)
- Revision mode: coloured revision sets, asterisks, locked scene numbers (12A, A1, OMITTED), A-pages.
- Live co-writing (Yjs over a relay), and sharing a read-only link. Needs a legal review first: sharing between users can bring the Online Safety Act into play (L17).
- Sync through the writer's own cloud folder.
- Index cards and a beat board.
- Story trackers: setups and payoffs, running gags, topical jokes with a check-before date.
- Rehearsal scripts with line numbers; a cue layer (lighting, sound, music).
- Musical analysis: each principal's "I want" song, songs per character, long gaps between songs.
- PDF import.
- An opt-in AI collaborator for structure and continuity feedback, using the writer's own API key, off by default. Needs a legal review first (docs/legal/legal-review.md, L17).
- A desktop wrapper for full file-system access.
- A translated interface, and right-to-left scripts.
