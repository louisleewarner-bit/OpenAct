# Interface copy

## Voice
Plain, warm and exact, like a good stage manager: says what happens, uses the writer's own terms, never jokes in an error. Sentence case everywhere except where the script format itself uses capitals.

## Vocabulary
One name per thing, used in menus, hints, announcements and help alike.

| Thing | Screenplay | Stage, musical, panto |
|---|---|---|
| Heading | Scene heading | Act; Scene |
| Description | Action | Stage direction |
| Speaker | Character | Character |
| Words spoken | Dialogue | Speech |
| Bracketed note in a speech | Parenthetical | Direction in speech |
| Song | (not used) | Song; Lyrics |
| Panto scene types | (not used) | Full stage; Front cloth |
| Where files go | "Saved in this browser" (prototype), "Saved on this device" (app) | same |

Write check titles as the finding, not the rule: "The title page shows a draft date", not "Draft date check". Say "consider", never "warning" or "error".

## Rules
- Buttons say what they do and keep that name through the flow: "Export PDF" leads to the PDF, "Save song" saves the song.
- Errors say what happened and what to do next, in that order, with no apology.
- Empty states say what will appear and how to make the first one.
- The app describes what it stores and where, in the same words every time.

## Localisation notes
- UK English is the default ("colour", "centred"); the vocabulary table is the translation glossary.
- Format terms (INT., EXT., CONT'D, MORE) are industry terms and are not translated.
- Key names in hints come from the platform (Ctrl or ⌘, Alt or ⌥).
