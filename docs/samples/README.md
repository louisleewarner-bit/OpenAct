# Sample scripts

Three short, original scripts, written for OpenAct following the creative-writing-partner guidance (original words only, family-safe panto, song spots with function, staging and feel). They ship with the app for first-run onboarding and double as test fixtures. They move to `packages/samples` in slice 1.

| File | Format | Shows |
|---|---|---|
| last-wash.fountain | Screenplay | A long speech that splits across pages with (MORE) and (CONT'D); automatic (CONT'D) after action |
| jack-and-the-beanstalk.fountain | Pantomime (UK layout) | Front-cloth and full-stage scenes, a "behind you", audience participation, numbered songs, a note, two full-stage scenes in a row (triggers the warning) |
| the-lighthouse-keepers-daughter.fountain | Musical (UK layout) | An opening number, an "I want" song with lyrics, and a reprise placeholder numbered 2a |

Each file is OpenAct Fountain (ADR-0002): plain Fountain readable in any Fountain app, with OpenAct's conventions and a trailing settings block.
