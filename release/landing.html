Sixteen formats, and your own

Screen

Screenplay, one-hour TV drama, single-camera and multi-camera comedy, UK studio sitcom and vertical micro-drama, with the numbering, acts and (CONT'D) each one expects.

Stage

UK and US stage plays, musicals with numbered songs, and pantomime with front-cloth and full-stage scenes.

Audio, comics and prose

UK radio drama with page-by-page cue numbers, audio drama and podcasts, comic scripts with pages and panels, and treatments.

Video games

Branching dialogue with nodes, player choices, conditions, barks and quest beats. A branch map checks every jump, recording line IDs can be locked, and you can export a recording sheet, Ink or Yarn Spinner files.

Real files out

PDF that matches the page on screen, line for line, with the font inside it. Word with a named style for every element. Fountain and Final Draft files too. An anonymous copy names no author anywhere.

Bring your own format

Import a Final Draft or Word template, check a sample page, and save it. “Find a format” lists common competition and theatre formats and links to each one's own page.

Ready to submit?

Checks a script against where it is going, such as a competition or a theatre, and shows the source for every rule.

Use it anywhere, offline

On a computer

  1. Download the zip and unzip it.

  2. Double-click the install file for your computer: Install OpenAct (Windows).cmd, (Mac).command or (Linux).sh. The first time, Windows or macOS will warn that it is not signed. The file is plain text you can read first.

  3. OpenAct then opens in its own window, from your Desktop or Start menu, and works with no connection. Or skip installing and just open OpenAct.html.

On a phone or tablet

  1. Open OpenAct in your browser.

  2. Use the browser's menu, or the Share button on an iPhone, and choose Add to Home Screen.

  3. Tap a key above the keyboard to switch element; tap Done to hide the keyboard.

Your scripts stay with you

OpenAct has no account and sends nothing anywhere. Scripts are kept on your device, and go nowhere unless you export them. Save to a file (Ctrl+S) for a copy you can back up or move, and open it again later.

Keep copies. Clearing your browser's site data, a private window, or a different browser or device starts empty. Save a file now and then, and export a PDF or Fountain file when you share. Fountain is plain text and opens in many programs.

Free, and open source

OpenAct is free software under the GNU General Public License, version 3 or later. The download includes the full source, the licences of everything it is built from, and checksums so you can check the files. Courier Prime and Atkinson Hyperlegible Next are used under the SIL Open Font License.

This is a public preview. It has been tested in Chrome on Linux, with automated checks on desktop and phone sizes. It has not yet been tried in Safari, Firefox, Word or Final Draft themselves, so please check an exported file before you send it anywhere important.
